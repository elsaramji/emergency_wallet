Emergency Wallet Overview

A smart, behavioral personal finance app built for the MENA region. Encouraging salaried users to build financial resilience by designing friction on withdrawal and ease on deposit.

MVP v1.0 Product Status
Clean Arch Architecture Style
Egypt (MENA) Target Market
Stripe-Inspired UI Aesthetic

Project Vision & Mission

The Mission

To help users track their money across multiple wallets and automatically enforce an emergency savings rule (20% auto-save), protecting their financial wellbeing *before* a crisis hits — not scramble for it during one.

The Core Philosophy

Most financial apps treat all goals equally. We build deliberate friction around the Emergency Wallet: withdrawing money is hard, depositing is easy. This prevents impulsive spending and preserves funds for genuine emergencies.

The Friction-Aware Framework

🔒

Emergency Lock Logic

A deliberate friction layer between clicking "Withdraw" and receiving cash. Users must confirm it's a true emergency before accessing funds.

📅

Monthly Bucketed Transactions

Transactions are grouped month-by-month for efficient querying, clean history, and intuitive aggregations instead of one endless list.

💸

Multi-Wallet Tracking

Unified view of Cash, Visa, and Smart Wallets (Vodafone Cash, Fawry) representing total liquid wealth.

Design Principles

The UI design takes a premium Stripe-inspired aesthetic, using modern typography, sleek gradients, and subtle shadows. The layout balances structural order with clean microcopy.

✨

Core Design Mantra

"The user should know their financial position within 3 seconds of opening the app."

🌍

Bi-Directional UX Parity

English (LTR) and Arabic (RTL) are built as first-class citizens. Mirroring animations, layout alignments, and gesture zones natively.

🏡

MENA Cultural Design Rules

Egypt MVP focuses on the "Cash Wallet" as the highest priority card, reflecting cash-first habits. Positive events use green (#00C48C) as a symbol of growth/blessing, while orange represents caution.
